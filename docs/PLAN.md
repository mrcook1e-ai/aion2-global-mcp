## Часть A: Остаточные баги из report.md (техдолг)

Все баги из раздела 3.2 отчёта (`C:\Users\mrcook1e\aion2-mcp\report.md`).

### A1. Души монстров `NPC #1025` в `get_session_tracker`
- **Симптом:** `topSoulsNpcs` выводит `"name": "NPC #1025"` (диапазон 1000–1200).
- **Причина:** Души используют особые малые NPC ID, которые не попадают в `database.getNpc`.
- **Файлы:** `internal/usecase/session_tracker.go`, `internal/usecase/resolver.go`
- **Решение:** Добавить Read-Through запрос для малых NPC ID в `NpcOrBossLabel`. Если `database.getNpc` не находит — попробовать `database.getItem` (души могут быть предметами) или хардкодить map ID→имя для диапазона 1000–1200.
- **Сложность:** Средняя — требуется исследовать API для этих ID.

### A2. Титулы и крылья без `name` в `list_my_characters`
- **Симптом:** Компактные объекты `equippedTitles: [{"id": 23010021}]` без имён.
- **Причина:** `ListCharacters` не вызывает резолвер для титулов и крыльев (только `GetCharacterOverview` делает).
- **Файлы:** `internal/usecase/character.go` (метод `ListCharacters`)
- **Решение:** Подключить `ResolveEntities(EntityTitle/EntityWing)` в `ListCharacters`, аналогично `GetCharacterOverview`.
- **Сложность:** Лёгкая (5 минут).

### A3. Системные билеты/таймеры без имён
- **Симптом:** `ticketId: 1, 3, 4, 9, 11, 101, 201–206, 60000001–60000010, 70000001+` без `name`.
- **Причина:** Эти ID не являются данжами. Это системные таймеры (ежедневные, еженедельные, PvP-лимиты), у которых нет записи в `database.getDungeon`.
- **Файлы:** `internal/usecase/character.go` (цикл по тикетам), `internal/domain/telemetry.go`
- **Решение:** Создать статичный маппинг `var systemTicketNames = map[int]string{1: "Дневной лимит", 3: "PvP-арена", ...}`. Эти ID фиксированные, их реверсят из клиента.
- **Сложность:** Средняя — нужно исследовать назначение каждого ID (запустить игру / проверить wiki).

### A4. Реликвии Пантеона без названий
- **Симптом:** `pantheon: [{"decoId": 10, "slot": 2}]` без имён.
- **Причина:** Нет процедуры `database.getPantheonDeco` в Questlog API. Данных о картинах Пантеона нет.
- **Файлы:** `internal/domain/telemetry.go` (`PantheonEntry`)
- **Решение:** Исследовать Questlog API на наличие процедуры для пантеона. Если нет — составить маппинг вручную (их конечное малое число).
- **Сложность:** Средняя.

### A5. Монолиты без названий регионов
- **Симптом:** `monoliths: [{"monolithId": 2001, "tokens": 560}]` без имён.
- **Причина:** Нет процедуры для монолитов. ID привязаны к игровым регионам.
- **Файлы:** `internal/domain/telemetry.go` (`MonolithEntry`)
- **Решение:** Аналогично пантеону — исследовать API или составить маппинг (конечный набор ~20 ID).
- **Сложность:** Лёгкая, если маппинг, средняя если искать API.

### A6. Автоатаки и проки предметов в боевых логах
- **Симптом:** `skill#16000000`, `skill#5004`, `skill#100055`.
- **Причина:** Это не обычные скиллы, а внутренние ID автоатак классов и проки оружия/рун. `database.getSkill` по таким ID возвращает пустоту.
- **Файлы:** `internal/usecase/resolver.go` (`SkillLabel`)
- **Решение:** Хардкод маппинг для известных ID авто-атак по классам (16000000 = авто-атака элементалиста, и т.п.) и проков. Диапазон конечный.
- **Сложность:** Лёгкая — нужно собрать ~10–15 ID.

### A7. Холодный старт `get_session_tracker` (таймаут)
- **Симптом:** При первом вызове парсинг 89 КБ `map-tracker.json` + массовый резолв NPC + обогащение ценами > 10 сек → таймаут MCP.
- **Файлы:** `internal/usecase/session_tracker.go`
- **Решение:**
  1. Кэшировать результат парсинга `map-tracker.json` в памяти (invalidate по mtime файла).
  2. Ленивый резолв NPC: первый вызов отдаёт данные с `NPC #ID`, фоновый горутин дообогащает и кэширует.
  3. Либо увеличить таймаут MCP-вызова для этого инструмента.
- **Сложность:** Средняя.

## Часть C: Технические решения Canvas

### C1. `file:///` vs HTTP endpoint
- **Проблема:** Chrome блокирует загрузку внешних ресурсов (шрифты, иконки) из `file:///`.
- **Решение:** Добавить `GET /api/v1/canvas/:view` в `httpapi/handler.go`. HTML отдаётся с правильными CORS-заголовками. Открытие через `http://127.0.0.1:PORT/api/v1/canvas/crafting_tree?recipeId=123`.
- **Бонус:** можно встроить превью в чат OpenCode через iframe или ссылку.

### C2. Размер HTML-файла
- **Проблема:** инлайн SVG-иконок раздувает файл до мегабайтов.
- **Решение:** иконки берутся с CDN Questlog (`https://questlog.gg/aion-2/assets/Game/UI/...`). Шрифты — Google Fonts CDN. В HTML инлайнятся только CSS, JS и JSON-стейт.

### C3. Синхронизация темы с OpenCode
- **Проблема:** `localStorage` недоступен из `file:///` другого origin.
- **Решение:** Go-генератор определяет текущую тему и передаёт `data-color-scheme="dark"` прямо в HTML при генерации. Либо query-параметр `?theme=light`.
