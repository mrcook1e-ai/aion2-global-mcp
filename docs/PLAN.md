## Часть A: Остаточные баги из report.md (техдолг)

Все баги из раздела 3.2 отчёта (`C:\Users\mrcook1e\aion2-mcp\report.md`).

### A1. Души монстров `NPC #1025` в `get_session_tracker` [РЕШЕНО]
- **Симптом:** `topSoulsNpcs` выводил `"name": "NPC #1025"` (диапазон 1000–1200).
- **Решение:** Добавлен метод `SoulLabel` в `Resolver` с поддержкой маппинга известных душ и fallback "Душа: <Name>" / "Душа монстра #ID".

### A2. Титулы и крылья без `name` в `list_my_characters` [РЕШЕНО]
- **Симптом:** Компактные объекты `equippedTitles: [{"id": 23010021}]` без имён.
- **Решение:** Пакетный резолв крыльев и титулов подключен в `ListCharacters`.

### A3. Системные билеты/таймеры без имён [РЕШЕНО]
- **Симптом:** `ticketId: 1, 3, 4, 9, 11, 101, 201–206, 60000001–60000010, 70000001+` без `name`.
- **Решение:** Добавлены `knownSystemTickets` и хелпер `resolveTicketName` с поддержкой спец-разломов, сезонных лимитов и тиров данжей.

### A4. Реликвии Пантеона без названий [РЕШЕНО]
- **Симптом:** `pantheon: [{"decoId": 10, "slot": 2}]` без имён.
- **Решение:** В `PantheonEntry` добавлено поле `Name`, добавлен справочник `knownPantheonNames` (15 реликвий Владык).

### A5. Монолиты без названий регионов [РЕШЕНО]
- **Симптом:** `monoliths: [{"monolithId": 2001, "tokens": 560}]` без имён.
- **Решение:** В `MonolithEntry` добавлено поле `Name`, добавлен справочник `knownMonolithNames` для регионов (Альтгард, Морхейм, Фоэта и др.).

### A6. Автоатаки и проки предметов в боевых логах [РЕШЕНО]
- **Симптом:** `skill#16000000`, `skill#5004`, `skill#100055`.
- **Решение:** Хардкод маппинг `knownAutoAttackNames` для автоатак классов и проков рун/оружия.

### A7. Холодный старт `get_session_tracker` (таймаут) [РЕШЕНО]
- **Симптом:** При первом вызове парсинг 89 КБ `map-tracker.json` + массовый резолв NPC + обогащение ценами > 10 сек → таймаут MCP.
- **Решение:**
  1. Кэширование снапшота `map-tracker.json` в памяти по mtime файла.
  2. Подсчет тоталов и выборка top-15 убийств и top-10 душ *до* резолва имен.
  3. Пакетный резолв недостающих NPC в один запрос.
  4. Ограничение и таймаут (4 сек) для котировок аукциона.

## Часть C: Технические решения Canvas

### C1. `file:///` vs HTTP endpoint
- **Проблема:** Chrome блокирует загрузку внешних ресурсов (шрифты, иконки) из `file:///`.
- **Решение:** Добавить `GET /api/v1/canvas/:view` в `httpapi/handler.go`. HTML отдаётся с правильными CORS-заголовками. Открытие через `http://127.0.0.1:PORT/api/v1/canvas/crafting_tree?recipeId=123`.
- **Бонус:** можно встроить превью в чат OpenCode через iframe или ссылку.

### C2. Размер HTML-файла
- **Проблема:** инлайн SVG-иконок раздувает файл до мегабайтов.
- **Решение:** иконки берутся с CDN Questlog (`https://questlog.gg/aion-2/assets/Game/UI/...`). Шрифты — Google Fonts CDN. В HTML инлайнятся только CSS, JS и JSON-стейт.

### C3. Синхронизация темы с OpenCode
- **Проблема:** `localStorage` недоступен из `file:///` другого origin.
- **Решение:** Go-генератор определяет текущую тему и передаёт `data-color-scheme="dark"` прямо в HTML при генерации. Либо query-параметр `?theme=light`.
