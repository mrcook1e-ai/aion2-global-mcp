## 3. Visual Canvas Engine (Текущее состояние)

- **Концепция:** Zero-Server Canvas (генерация автономного HTML5-артефакта с вшитым JSON-стейтом, открытие в браузере через системный протокол или локальный HTTP, 0 фоновых демонов Node.js).
- **Дизайн-система:** OpenCode V2 Tokens (поддержка Dark/Light, шрифты Inter + IBM Plex Mono).
- **Реализованный модуль:**
  - `crafting_tree` (Модуль 3 из спецификации):
    - Полноценный интерактивный SVG DAG-граф слева направо (ингредиенты → продукт).
    - Цветовая маркировка (🟢 в сумке, 🟡 частично / крафтить, 🔴 докупить на аукционе).
    - Pan & Zoom (колёсико + drag).
    - Инспектор справа: экономика (себестоимость, маржа, шанс успеха, профит многоступенчатого крафта), список материалов.
    - Модалка «🛒 Список покупок на аукционе» с кнопкой копирования в буфер.
    - **Реальные CDN-иконки предметов:** парсятся по формуле `https://cdn.questlog.gg/aion-2{iconPath_without_suffix}.webp`.
    - **Вывод в чат OpenCode:** богатая Markdown-карточка с кликабельной ссылкой, таблицей экономики и ингредиентов.
